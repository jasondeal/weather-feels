WEATHER FEELS — STATE DEMO CODES
==================================
Enter any of these 6-digit codes in the zip code field to force the app into a
specific visual/message combination, bypassing the weather API entirely.
Useful for testing every possible app state without needing real weather data.

Code format:  2001XX = Sunny background
              2002XX = Cloudy background
              2003XX = Rainy background  (rain message always shown for rainy)

              XX01 = Hotter          (Day N is more than 10°F warmer than Day N-1)
              XX02 = Warmer          (8–10°F warmer)
              XX03 = A little warmer (3–7°F warmer)
              XX04 = About the same  (within 2°F either way)
              XX05 = A little cooler (3–7°F cooler)
              XX06 = Cooler          (8–10°F cooler)
              XX07 = Colder          (more than 10°F cooler)

Note: Rainy states always display "Rain is expected." Sunny and cloudy states
never display a rain notice. This matches the app's actual weather logic.

NOTES
-----
- State codes call showWeather() directly — no API calls are made.
- The location pill displays "Demo" instead of a real city name.
- The header shows "Today will be:" (demo codes always render as daytime).
- Nothing is saved to localStorage when a state code is used.
- Total coverage: 3 backgrounds × 7 temperature messages = 21 app states.
- Sunny/cloudy states cannot show rain; rainy states always show rain.
  This mirrors the actual app logic (same precipitation threshold drives both).
